Mission Control v1 Sprint Plan (Discord SOP Format)

  1. Problem: current war-room has wiring but lacks one coherent mission layer that ties build actions to revenue outcomes.
  2. Scope In: command dashboard, event instrumentation baseline, sentry/posthog wiring, n8n trigger stubs. Scope Out: full CRM migration, broad Gmail automation.
  3. Acceptance Criteria:
    • One Mission Control page renders live status blocks.
    • PostHog captures 8 core events.
    • Sentry captures frontend error + trace sample.
    • n8n webhook receives one test event from war-room.
  4. Tasks:
    • Create `/app/mission-control/page.tsx` with modules (Revenue, Pipeline, Build Queue, Alerts).
    • Add `lib/analytics/events.ts` and typed track helpers.
    • Wire PostHog provider + key events.
    • Wire Sentry SDK + basic tracing/release tags.
    • Create `n8n` webhook connector and test flow.
  5. Validation: lint + typecheck + smoke route test + event fire verification + sentry test error.
  6. Rollback: isolate on feature flag (`mission_control_v1`) and keep branch rollback snapshot.
