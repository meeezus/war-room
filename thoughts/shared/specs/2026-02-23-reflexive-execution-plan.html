The Word You Were Looking For

Reflexive — from Latin reflexus, "bent back." A system that acts on its own output. The engine stops being a CI pipeline (open-loop) and becomes a cybernetic agent (closed-loop). Sprint 2 is emergent from Sprint 1's actual results, not pre-planned.

Open-Loop vs Closed-Loop

Today (Open)

proposal
  ↳ council
  ↳ mission
  ↳ tasks
  ↳ done. stop.

// dead end
// no feedback
// fire & forget

Reflexive (Closed)

objective
  ↳ proposal
  ↳ mission
  ↳ tasks
  ↳ evaluate
  ↳ replan ↳ proposal
     ↳ loop...

5 Safety Layers

1
Iteration cap — max 5 missions per objective (configurable)
2
Kill switch — SET status='paused' stops loop instantly
3
Council gate — follow-ups enter normal review pipeline
4
Cost gate — existing cap_gates auto-approve limits apply
5
Stall detection — poller catches orphaned objectives
